# Security policy

If you find a security issue in Termxxle, please report it privately through GitHub's
private vulnerability reporting for this repository:

https://github.com/xjustanoah/Termxxle/security/advisories/new

Do not publish exploit details before the maintainer has had a reasonable
chance to investigate and prepare a fix. If private reporting is unavailable,
contact the maintainer through the GitHub profile at
https://github.com/xjustanoah.
